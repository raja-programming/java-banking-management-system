# Java Banking Management System

## Project Overview

This is a console-based Java Banking Management System developed using Object-Oriented Programming concepts.

The application allows a user to deposit money, withdraw money, check balance, view account details, and view transaction history.

## Features

- Deposit money
- Withdraw money
- Check account balance
- View account details
- View transaction history
- Handle invalid input using exception handling

## OOP Concepts Used

- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Abstraction
- Interface Implementation
- Method Overriding
- Access Modifiers
- Polymorphism
